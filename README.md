# Oblix Studio website

A static, responsive portfolio website prepared for GitHub Pages. It uses the supplied Oblix Studio branding and project media, with no framework or build step.

## Included project media

- `assets/media/background-loop.mp4` — web-optimised version of the supplied `Background.mov`, used as the looping landing-page background.
- `assets/media/22-minutes-trailer.mp4` — web-optimised H.264 version of the supplied trailer.
- `assets/media/woe-intro.mp4` — web-optimised H.264 version of the supplied Woe footage.
- `assets/images/thalassophobia.webp` — optimised version of the supplied Thalassophobia screenshot.
- `assets/images/oblix-wordmark.png` and `oblix-mark.png` — cropped versions of the supplied transparent logo.

The video files were converted to browser-friendly H.264 and reduced in size so they are safer to commit and quicker to stream from GitHub Pages.

## Before publishing

1. The contact form and direct email link are configured for `oblixstudio@gmail.com`.
2. Review the project descriptions and update any wording as the games develop.
3. Add additional social links later if required.

## Publish with GitHub Desktop

1. Unzip this folder.
2. Open GitHub Desktop and choose **File → Add local repository**.
3. Select the `oblix-studio-site-final` folder. If prompted, choose **Create a repository**.
4. Commit all files, then click **Publish repository**.
5. On GitHub.com, open the repository and go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then save.

The site will be published at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Local preview

Double-click `index.html`, or use VS Code Live Server. For the most accurate video and navigation testing, use a local server rather than opening the files directly.
